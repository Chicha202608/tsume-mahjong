# Tsume-Mahjong (ツモ山可視化・詰め麻雀)
ツモ山がすべて可視化された状態で戦う、パズル要素の強い情報完全開示型の麻雀ゲームです。
カンのタイミングによる「ツモ順のズレ（未来干渉）」やフリテンガードを考慮しながら最適な手順を導き出す、詰将棋のような高度な戦略性を重視しています。

## 現在実装済みの機能
麻雀の基本フロー（配牌、ツモ、打牌、鳴き）

複雑なカン処理（暗カン・大明槓・加槓の描画および山・嶺上牌の正確な同期）

リーチ処理および暗カン後のリーチ判定

フリテン判定（自分の河によるフリテン、リーチ後見逃しフリテン）

ツモ・ロンの和了選択 / 見逃し処理

## 三人モード

トップ画面の「三人モード」から開始します。通常の四人モードと同様、自分が操作し、他家2人は手牌を伏せてツモ切りします。席順は東→南→西→東です。萬子2〜8を除いた108枚を使い、13枚ずつ配牌、王牌14枚、通常山55枚で開始します。赤牌は五筒・五索の各1枚です。チーはできず、ポン・暗槓・加槓・大明槓は可能です。萬子のドラ表示は一萬→九萬→一萬と循環します。

北は手牌に残すか、自分のツモ後に「北抜き」で抜くかを選べます。手牌の北を抜いた場合は元のツモ牌を手牌に取り込み、通常山の末尾から補充します。連続して抜くこともできます。北抜きは門前を維持し、一発は消えます。槓ドラは増えず、嶺上牌は消費せず、補充牌で嶺上開花・海底摸月は付きません。リーチ後はツモった北だけ抜けます。山が空の場合は抜けません。

抜いた北は1枚1翻の抜きドラです。表示牌・裏表示牌によって北がドラなら、その分も抜いた北に加算します。抜きドラだけでは和了できず、役満には加算しません。点数はツモ損ありで、親の満貫ツモは4,000点ずつの計8,000点、子の満貫ツモは親4,000点・子2,000点の計6,000点です。ロン点数は四人モードと同じです。流局時は既存の詰め麻雀と同じく、自分のテンパイで3,000点、ノーテンで0点とします。

AIは3人のツモ順・ツモ損・北抜きを使って手順を比較します。最初に、自分のツモ後に抜ける北を順に抜いた場合の補充牌と残り山を確定し、その経路の手牌候補をまとめて1回列挙します。この初期探索は最大6秒で、有力な結果は見つかり次第表示します。その得点を基準に、北を残す門前手・暗槓・北抜きとポンや槓を組み合わせる手順も探索します。手牌を揃えられる時点より前にしか和了牌が出ない候補と、楽観的な得点上限でも最良手順に届かない候補は、手順再生前に除外します。門前探索にも最良得点を渡し、フリテンのロンや改善できない結果を除外します。採点・和了可否判定は段階間で解析結果を共有し、抜き北の枚数が違う場合も役・符の解析を再利用します。国士無双などの北を残す手も対象です。探索全体で約60秒の期限を共有し、候補列挙にも途中終了判定を入れています。全局面の最大得点は保証しません。「戻る」「進む」「待った」は抜いた北・補充牌・山を含めて復元します。`?example=sanma-nuki` を付けてトップ画面から三人モードを選ぶと、手牌の北→補充された北→補充牌ツモ和了を確認できます。

## 一人四人麻雀

トップ画面の「一人四人麻雀」から開始します。一人で四席とも操作するモードです。場風は開始・新局ごとに東・南・西・北からランダムに決まり、役判定にも反映されます。局数、持ち点、供託、点数移動は表示せず、和了時の役・符・翻・得点は表示します。既存の四人モードと同じ卓・メニュー・手牌操作の配置を使い、操作・応答する席が画面下に移ります。全員の手牌・副露（暗槓を含む）を公開し、手牌・河・副露は各席から見た向きに回転します。「山」ボタンで牌山と王牌の全牌を確認できます。牌山の黄色い強調は、鳴きが入らなければ現在の視点の席がツモる牌です。鳴きや槓で手番順が変わると再計算します。

打牌後は鳴き・ロンが可能な席の応答を順番に確認し、全応答が揃ってから解決します。複数ロンを採用し、ロン、ポン・大明槓、チーの順に優先します。同順位は打牌席から近い順、供託も最も近い和了者が取得します。加槓への槍槓、国士無双による暗槓へのロン、各席のフリテン・一発・リーチ供託、四席間の和了・流局精算に対応します。途中流局と流し満貫は採用しません。流局時の供託は卓上に残り、「新局」では全席25,000点に戻ります。

「戻る」「進む」は打牌・リーチ・鳴き応答などの判断場面を一つずつ移動し、視点や牌山の強調も復元します。「進む」は記録済みの操作だけを再生します。過去の場面で違う操作を選ぶと、確認後にそれ以降の履歴を置き換えます。「待った」は一つ前の判断場面まで戻って以降の履歴を削除します。本モードではAI探索処理を起動せず、AI得点比較やAI手順再生も表示しません。

## AI探索の範囲（二人・四人モード）
AIは配牌と今後の自分のツモから、通常形・七対子・国士無双のテンパイ候補を直接列挙します。七対子は異なる6種類の対子と1種類の単騎待ちを対象とし、同じ牌4枚を2対子として扱いません。門前の候補に対して、暗槓を最大2回行う探索も実行します。

さらにチー・ポン・大明槓・暗槓で最大4面子を作り、ポン後の加槓も探索します（最大4ポン＋4加槓の8操作）。副露は門前・暗槓の得点を厳密に上回る手順だけを採用し、同点なら門前を優先します。比較基準が満貫以上なら従来どおり副露は跳満以上に限定します。比較基準が満貫未満なら、先に跳満以上を探索し、それで満貫に届かなかった場合は跳満未満も追加探索します。鳴くたびに変わるツモ順・捨て牌の相手を使って次の副露候補を作り、大明槓では嶺上ツモ・山末尾の補充・追加ドラを反映します。同じドラ表示牌の重複も数え、役・ドラの楽観的な翻数上限で低打点の最終形を除外してから手順を復元します。形の列挙自体は各副露候補で行い、上限判定によって手順探索・採点の回数を減らします。

候補ごとに実際のツモ順で到達できる手順を再現し、既存のフリテン判定・和了採点を通じて得点を比較します。通常形と七対子が重なる手牌は待ちを統合します。探索全体は約60秒を目安とし、門前・暗槓探索後の残り時間を副露探索に使います。副露候補を順に展開し、暗槓・加槓可能な自分のツモ後・嶺上ツモ後も調べます。鳴く前の暗槓から副露へ続く手順も対象です。門前探索や処理中の候補によっては目安を超える場合があります。改善した手順は探索中にも表示し、時間切れではそれまでの最良手順を残します。低打点の追加探索では符数による得点差を見落とさないよう、満貫未満を翻数だけで除外せず実際に採点します。追加探索の時間を残すため、比較基準が満貫未満の場合は高打点探索に副露探索枠の半分までを割り当て、残り時間を追加探索に使います。全局面の最大得点を保証する探索ではありません。

テスト局面「4ポン＋4加槓（四槓子）」または `?example=four-pon-kakan` で8操作の手順を確認できます。テスト局面「副露3回で跳満」、または `?example=three-open-haneman` で白・發・一萬をポンして12,000点を和了する問題を再現できます。2回副露の確認用には `?example=two-open-haneman` も使えます。
