# 三人探索の採点再利用・期限共有

2026-10-21、seed 20261021。`nukiFirst.bench.ts` と同じ108枚から取り出した配牌を使用。
北抜き優先→北を残す門前→混合探索を比較した。暗槓専用の段階は両方とも含めていない。
北抜き優先・混合探索は各1秒、変更後の全体期限は10秒。変更直前のソースを一時コピーして比較し、比較後にコピーを削除した。

| 指標 | 変更前 | 変更後 |
| --- | ---: | ---: |
| 短い山（10枚）の最終得点 | 18,000点 | 18,000点 |
| 短い山の役・符解析呼び出し | 74回 | 16回 |
| 短い山の時間（単回） | 87 ms | 47 ms |
| 通常山（55枚）の最終得点 | 24,000点 | 24,000点 |
| 通常山の役・符解析呼び出し | 6,345回 | 5,402回 |
| 通常山の時間（単回） | 3,052 ms | 3,005 ms |

役・符解析の呼び出しは `riichi-score.calculate` をラップして直接数え、手順検証用の再採点を除外した。
短い山では約78%、通常山では約15%の解析を削減した。通常山では探索枠を使い切るため、今回の総所要時間の短縮は小さい。
時間制限付き探索と単回測定なので、全局面で同じ削減率や得点を保証する数値ではない。

北を残す門前探索では、5,752候補のうち最良得点を上回る結果を返さなかった候補が5,533、手順の再現は1,265回だった。
全ての出力を実際の状態遷移で再生し、再採点が一致することを確認した。
短い山はseed 17・771・2026・81・129でも変更前後の得点が下がらないことを確認した。

## 実装上の変更

- 各段階で1局分の採点キャッシュを共有。モード・抜き北枚数・赤牌・役フラグを区別する。
- 役・符の解析は北抜き枚数が違っても再利用し、抜きドラと三人分の支払いを再計算する。元の解析結果は変更しない。
- 手牌の並び順・物理牌IDによる同一入力の重複を取り除く。
- ロン・ツモ可否判定も同じ解析を使う。
- 北抜きの最良得点を門前探索にも渡し、フリテンのロンや改善できない結果を除く。重い上限採点は同じ候補に4回以上の和了機会がある場合に限定する。
- 門前・流局・暗槓の候補列挙に共有期限を渡し、期限切れでは既存の最良結果を返して後段を起動しない。

継続測定:

`node node_modules/vitest/vitest.mjs run --config experiments/vitest.config.ts experiments/sanmaReuse.bench.ts`

このコマンドは現在の実装を測定する。変更前の値は上記の記録を参照。
