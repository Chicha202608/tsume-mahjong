# 加槓を含む副露探索の再実測（2026-10-17）

前回と同じ100シード（整数20261016〜20261115）、四人麻雀・南家・東家開始、通常山70枚で順次測定。CPUはIntel Core i5-10400 2.90GHz。門前探索と最大8秒の既存暗槓探索で比較基準を求め、その得点を超える跳満以上の副露手順を探索した。副露探索の安全上限は各局180秒。

実験用 openSearchKakan.ts ではチー・ポン・大明槓に加え、ポン済み面子への加槓を自分の通常ツモ後・嶺上ツモ後に列挙する。加槓による面子数は増やさない。各面子の加槓は1回、面子は4つ、槓は4回という制約により最大8操作となり、操作回数での人工的な打ち切りはない。加槓可能になった後の見送りと後の巡目での実行も列挙する。嶺上牌、追加ドラ、山末尾の補充、鳴いた後の座席順を反映。候補ごとの打牌復元方式は既存方式を継続。

前回の操作数ごとの繰り返し列挙から、各計画を一度評価して後続操作を展開する深さ優先列挙にした。したがって時間差は加槓の枝の増加だけを単独測定した値ではなく、実験実装全体の比較。

| 測定 | 前回：加槓なし | 今回：加槓あり |
|---|---:|---:|
| 全体平均 | 1.390秒 | 1.917秒 |
| 全体中央値 | 0.937秒 | 1.208秒 |
| 全体95パーセンタイル | 4.432秒 | 5.057秒 |
| 全体最大 | 4.850秒 | 7.334秒 |
| 副露探索平均 | 0.851秒 | 1.363秒 |
| 副露探索最大 | 4.463秒 | 6.728秒 |
| 副露探索の時間切れ | 0/100 | 0/100 |

100件すべて手順再生・採点照合を通過し、前回との最大得点の差は全件0。69局面で加槓を含む候補が実際に列挙され、計25,246候補。各局面で列挙した最大操作数の分布は2操作1件、4操作31件、5操作56件、6操作11件、7操作1件。無作為100局面では8操作に達しなかったため、別途人工局面 kakanSanity.bench.ts で4ポン＋4加槓の8操作から四槓子の和了まで探索・再生を確認した（約1.54秒、8操作の計画105件）。

今回の条件では1局あたり分単位の待ち時間は発生しなかった。ただし100局面の実測であり、最悪時間の保証ではない。暗槓と副露の混在・すべての打牌順の全探索は引き続き対象外。門前側の暗槓探索は既存の時間制限を維持している。アプリ本体の探索は変更していない。
